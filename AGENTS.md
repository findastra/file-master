# File Master

Part of Astra's Pet Apps. Public credit: Astra.

Keep existing product behavior and source intact. The web app is file-master-20261008.html; metadata is pet.json. Never commit credentials, personal health or finance data, local settings, caches, or logs. Imported or user-entered text must be rendered as text, not HTML. State integration limits plainly. New filenames use lowercase words and a date immediately before the extension.

Web app and art integration: OpenAI Codex (GPT-6), 2026-10-08.

Pet words: use one name per part of a pet app, as listed in the Cage's [PET-WORDS.md](https://github.com/findastra/astras-pet-apps/blob/main/PET-WORDS.md). `agent/file-master.md` tells the agent how to apply them to file names. Added with Claude Opus 5.5 (`claude-opus-5-5`), 2026-10-09.
